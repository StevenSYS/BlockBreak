# Controls

| Key            | Action                                         | 
| -------------- | ---------------------------------------------- | 
| Up             | Move Up                                        | 
| Down           | Move Down                                      | 
| Left           | Move Left                                      | 
| Right          | Move Right                                     | 
| Enter          | Restart                                        | 
| Escape         | Quit                                           |

# Controls (3DS/2DS)

| Button                           | Action                                         | 
| -------------------------------- | ---------------------------------------------- | 
| D-Pad Up, Circle Pad Up, X       | Move Up                                        | 
| D-Pad Down, Circle Pad Down, B   | Move Down                                      | 
| D-Pad Left, Circle Pad Left, Y   | Move Left                                      | 
| D-Pad Right, Circle Pad Right, A | Move Right                                     | 
| Select                           | Restart                                        | 
| Start                            | Quit                                           |
